🚀 Запуск проєкту

Проєкт використовує PostgreSQL для зберігання користувачів та іншої інформації. Встанови PostgreSQL локально або використовуй сервіс типу Supabase / Render.

1. Склонуй репозиторій
2. Налаштуй змінні середовища:
  - Створи `.env` файл в `backend` на основі `.env.example`.
3. Встанови залежності командою `npm run install:all`
4. Створи базу даних:
  - Переконайся, що в `.env` змінна `DB_DATABASE` має унікальну назву
  - Ініціалізуй базу даних командою `npm run db:init`

УВАГА: якщо в твоєму середовищі вже є база з такою назвою, db:init може її перезаписати!

5. Запусти проєкт командою `npm run dev`
6. Посміхнись
